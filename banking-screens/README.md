# Watermelon Banking Design Screens

This pack is a lightweight design handoff for the current banking application.
It is based on the implemented product flows and organized like a compact Figma-style screen export set.

Included screens:
1. Banking login
2. Banking dashboard overview
3. Transfer money flow
4. Statement generation flow
5. Banking admin view

Format:
- SVG vector artboards for easy preview and reuse
- One screen per file

Notes:
- These are design-board style representations of the current implemented UI, not pixel-perfect browser screenshots.
- The pack is intended for discussion, review, handoff, and future design iteration.
